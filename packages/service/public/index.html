drip

Push a screenshot or file to your drip server, get back a short auto-expiring URL your agent can fetch.

Install

curl -fsSL __DRIP_BASE_URL__/install.sh | sh

Installs the drip binary to ~/.local/bin. macOS (Apple Silicon / Intel) and Linux (x64 / arm64).

Use

  • drip ~/screenshot.png — upload a file; the URL is printed and copied to your clipboard
  • drip a.png b.pdf — upload several at once
  • drip clip — upload the file(s) or image on the clipboard (macOS, Wayland, X11)
  • drip list — show recent uploads
  • drip get <id> — download a file back into the current directory

For agents

The CLI is self-describing — run drip --help for the full command surface. An agent can push, list, and pull files with no knowledge of the HTTP API.

Raycast

Install the Send to drip Raycast script command — one hotkey to upload the clipboard file/image (or the Finder selection):

drip raycast

Then add ~/.raycast-scripts once under Raycast → Settings → Extensions → Script Commands → “Add Directories.” Prefer to do it by hand? Download the script and drop it in a Raycast script-commands folder.

How it works

You push bytes to drip; it stores them and returns a short /f/<id> URL. An agent (or curl, or a browser) fetches that URL directly, or discovers recent files with drip list. Files auto-delete after their TTL (default 24h, max 7d).
